# EnhanceX Next Generation Release Notes (v1.1.0 - v2.0.0)

We are thrilled to announce the release of the **EnhanceX Next Generation AI Media Enhancement Platform**.

This release expands EnhanceX into a modular, enterprise-grade AI media processing platform featuring:

- **Adaptive AI Enhancement Engine (AAE):** Automatic classification and pipeline construction for 9 domain categories (Portrait, Landscape, Anime, Document, Night, Medical, Satellite, Artwork, Screenshot) and 8 quality defect types.
- **Model Management System:** `enhancex models` CLI with SHA-256 integrity verification, checksums, and local discovery.
- **Modular Ecosystem:** Subpackages for audio, document, anime, medical, satellite, face, studio, server, sdk, and cuda.
- **Research & Benchmark Mode:** `ImageEnhancer(mode="manual", model="RealESRGAN")` for reproducible AI evaluation.
- **Enterprise Platform:** Multi-GPU Cluster Manager, Enterprise SDK Client, Prometheus Telemetry Exporter, and Kubernetes Deployment manifests.

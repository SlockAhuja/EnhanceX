# Contributing to EnhanceX

Thank you for your interest in contributing to **EnhanceX**! We welcome contributions from developers, researchers, and AI enthusiasts.

---

## 🛠 How to Contribute

### 1. Reporting Bugs & Issues
- Search existing issues before creating a new one.
- Provide OS, Python version, GPU hardware, driver versions, and complete error tracebacks.

### 2. Code Contributions & Pull Requests
- Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
- Adhere to **Clean Architecture**, **SOLID** principles, and Modern **C++20** / **Python 3.8+** standards.
- Run tests prior to submission: `pytest tests/`.
- Ensure all commits use descriptive semantic commit messages.

### 3. Coding Style
- **Python**: Follow PEP8 guidelines and use `black` / `flake8` for formatting.
- **C++ / CUDA**: Follow Google C++ Style Guide and standard LLVM formatting.

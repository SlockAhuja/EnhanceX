# Contributing to EnhanceX

We welcome contributions from the open-source AI and computer vision community!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Create a feature branch**: `git checkout -b feature/my-new-algorithm`.
3. **Write tests**: Ensure all unit tests pass and code coverage remains above 90%.
4. **Follow Code Quality Rules**:
   - Python code must conform to Black formatting and standard type hints.
   - C++ code must adhere to C++20 modern standards.
5. **Open a Pull Request**: Provide a detailed description of your changes.

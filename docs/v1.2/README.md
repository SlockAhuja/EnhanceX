## Overview

EnhanceX v1.2.0 introduced the Adaptive AI Enhancement Engine (AAE) for automated category detection and quality defect analysis.

### Adaptive Auto Mode (v1.2.0)
```python
from enhancex import ImageEnhancer

enhancer = ImageEnhancer(mode="auto")
out = enhancer.enhance("sample.jpg", "enhanced.jpg")
```

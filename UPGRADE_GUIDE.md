# EnhanceX Upgrade Guide

## How to Upgrade

Run the standard upgrade command:
```bash
pip install --upgrade enhancex
```

Verify your installation post-upgrade:
```bash
enhancex doctor
enhancex version
```

### Breaking Changes Notice
There are **NO breaking changes** in this release. All existing code using `ImageEnhancer`, `VideoEnhancer`, `Stabilizer`, or `SuperResolutionEngine` continues to work without modification.

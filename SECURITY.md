# EnhanceX Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a paramount priority for the EnhanceX framework. If you discover a security vulnerability (such as a buffer overflow in CUDA/C++ extensions, path traversal, or insecure deserialization):

1. **Do NOT open a public GitHub issue.**
2. Send an email to security@enhancex.org with details, reproduction steps, and potential impacts.
3. Our security response team will acknowledge receipt within 24 hours and issue a patch within 7 business days.

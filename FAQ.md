### Q1: What is EnhanceX?
EnhanceX is a modular AI media enhancement platform designed for image, video, audio, document, anime, medical, and satellite processing.

### Q2: What is the Adaptive AI Enhancement Engine (AAE)?
AAE is an automated feature in EnhanceX v2.0.0 that classifies input media into 9 domain categories and detects 8 quality defect types to build and execute an optimal enhancement pipeline.

### Q3: How do I run diagnostics?
Run `enhancex doctor` in your terminal.

### Q4: How do I manage model weights?
Use `enhancex models list`, `enhancex models install <name>`, and `enhancex models verify`.

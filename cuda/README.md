# EnhanceX CUDA Kernel Acceleration Engine

This directory links to the native C++/CUDA kernel sources located in [`cpp/src/gpu/cuda_kernels.cu`](../cpp/src/gpu/cuda_kernels.cu).

## Features
- **Laplacian Image Sharpening**
- **Spatial Bilateral Denoising**
- **Color Transformations (RGB <-> BGR, Grayscale)**
- **Bilinear Rescaling**
- **HDR Reinhard Tone Mapping**
- **Brightness & Contrast Adjustments**
